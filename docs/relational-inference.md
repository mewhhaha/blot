# Bounded relational inference

The compiler can establish normal-return integer relationships through source
helpers and infer accumulator bounds for directly called local self-tail
recursion. This also covers the ordinary recursion generated by `for`.

The executable example is
[relational_inference.blot](../examples/relational_inference.blot), with helpers
in [its library](../examples/lib/relational_inference.blot). It covers an
increment helper, a nonnegative result, constructor-qualified bounds, explicit
recursion, and a traversal with early exit. Their ordinary types remain
unchanged.

Run the focused gate after rebuilding the compiler:

```sh
pnpm compiler:build
pnpm test:refinements
```

The gate checks helper and loop acceptance, incorrect offsets, negative entries,
invalid back edges, wrong arrays and constructor payloads, escaping recursion,
forged proof observations, and bounded replay. Browser-compatible Wasm tests
compare normal results with the evaluator through source imports and source-free
capsules. They also check cache reuse and invalidation, explanations, an
overflow trap, and a 100,000-element traversal.

`blot explain` now reports refinement facts at a proved access or recursive
body. Compiler-host ABI 8 and certificate schema 21 carry these erased
observations; Runtime HIR 13 and guest ABI 4 retain their existing
representation.

This is a bounded relational fragment. It does not infer caller preconditions,
prove termination, or support arbitrary nonlinear invariants. Imported proof
observations are explanations; caller assumptions are derived from the resolved
source closure. The normative contract is in [SAFETY.md](../spec/SAFETY.md).

## Validation

Verified on 2026-09-11 with compiler artifact
`2d1c2007f76ad4068c785e08b5e78aca13d3e164f4d855d9bd525194e4b9641e`:

- 558 native tests, including nonzero accumulator starts and inline index
  arithmetic.
- 271 Node tests; the focused refinement gate includes 11 Node cases.
- 23 evaluator/Wasm conformance observations.
- 218 corpus examples compiled, with no refusals or failures.
- Six package checks, generated-schema checks, and TypeScript checking.

The production development benchmark used the 5,273,553-byte, 20-module workload
and ten edits. Median commit-to-activation time was 160.9 ms, with a 524.2 ms
p95. Each edit rebuilt one module and retained 19; maximum observed RSS growth
was 10,014,720 bytes. The 100 ms latency target remains unmet. These
shared-machine measurements are not a controlled before/after performance
comparison.

```sh
pnpm benchmark:development -- --samples=10 --report-only --output=/tmp/blot-refinements.json
```
